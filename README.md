# 📲 SMS Spam Classification – NLP & Machine Learning

This project focuses on classifying SMS messages as **spam** or **ham** (non-spam) using Natural Language Processing (NLP) and classic machine learning algorithms. The entire pipeline is implemented in a Jupyter Notebook (`spamClassification.ipynb`) including data preprocessing, model training, evaluation, and comparison.

---

## 🔍 Features

- **Dataset**: Based on the [UCI SMS Spam Collection Dataset](https://www.kaggle.com/datasets/uciml/sms-spam-collection-dataset), which contains 5,574 labeled SMS messages (13.4% spam).
- **Preprocessing**: 
  - Lowercasing
  - Removing punctuation and stopwords
  - Tokenization
  - Lemmatization
- **Feature Engineering**: TF-IDF vectorization
- **Models Compared**: 
  - Naive Bayes
  - Logistic Regression
  - Support Vector Machines (SVM)
  - Random Forest
- **Evaluation Metrics**: Accuracy, Precision, Recall, F1-score
- **Fully notebook-based**: Easy to understand and modify in Jupyter Notebook
